# bectl-tui

Interface de terminal (TUI) para o [`bectl(8)`](https://man.freebsd.org/cgi/man.cgi?bectl(8))
do FreeBSD, para gerenciar Boot Environments ZFS — a contraparte de terminal do
[bectl-gui](https://github.com/cleberalves40/bectl-gui), com ícones
[Nerd Fonts](https://www.nerdfonts.com/).

Em desenvolvimento.
